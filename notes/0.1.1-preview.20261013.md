LanPebble 0.1.1 미리보기 버전입니다.

### 변경 사항

- 설정에서 현재 버전을 확인하고 빌드 정보를 펼쳐 복사할 수 있습니다.
- 모바일 웹의 언어·테마 선택을 상단 설정 버튼으로 접었습니다. 17개 언어와 키보드 조작을 지원합니다.
- 웹 설정을 열거나 닫아도 로그인과 파일 선택·업로드 대기열을 유지합니다.
- 앱이 사용 중이면 설치 파일이 교체 전에 종료를 안내합니다. 전송 중인 앱을 강제로 종료하지 않습니다.
- 이전 버전에서 업데이트할 때 기존 설치 경로·바로가기·설정·기기 인증 정보를 유지합니다.
- 앞으로 배포 파일과 변경 사항은 이 공개 저장소에서 제공합니다.

### 다운로드

- `LanPebble-0.1.1-preview.20261013-win-x64-Setup.exe`: 현재 사용자에게 설치하는 버전
- `LanPebble-0.1.1-preview.20261013-win-x64.zip`: 전체 압축 해제 후 실행하는 포터블 버전
- 각 파일의 `.sha256` 체크섬을 함께 제공합니다.

Windows 10 버전 2004 이상 또는 Windows 11의 x64 환경용입니다. 필요한 .NET/ASP.NET Core 및 Windows App SDK 런타임이 포함됩니다. 업데이트 전에 진행 중인 전송을 완료하고 앱을 완전히 종료하세요.

미리보기 빌드는 코드 서명 전이므로 Windows가 게시자 경고를 표시할 수 있습니다. 웹 접속은 HTTP를 사용하므로 신뢰할 수 있는 로컬 네트워크에서 사용하세요.

English: Settings now show the app version and expandable build details. Mobile web language/theme controls collapse into an accessible settings toggle without clearing the upload queue. Installer updates check for a locked executable before replacing files and retain the previous install path, shortcuts and settings. Required runtimes are included. These unsigned preview builds are intended for trusted local networks; web access uses HTTP.
