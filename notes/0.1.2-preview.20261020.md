# LanPebble 0.1.2-preview.20261020

Windows x64 preview · 설치형 EXE / 포터블 ZIP

## 변경 사항

- 호스트와 각 연결 기기 사이의 1:1 메시지: Windows 앱과 웹 모두 지원합니다. 최근 50개 메시지를 메모리에 보관하고 연결 해제·차단·공유 종료 시 삭제합니다. 필요한 대화만 텍스트로 직접 저장할 수 있습니다.
- Windows 앱은 새 메시지 알림과 안 읽은 개수를 표시합니다. 웹은 별도 권한 없이 화면 안에 토스트를 표시합니다. 대화를 읽는 중에는 중복 알림을 생략합니다.
- 연결 승인 스위치는 OFF가 수동 승인, ON이 자동 승인입니다. 새 설정의 기본값은 수동 승인이고, 기존에 저장한 선택은 유지합니다.
- 업로드 대기열에서 여러 항목을 선택해 저장 경로를 함께 변경하고 원본→대상 경로를 확인할 수 있습니다. 시작한 폴더의 재시도 경로는 변경을 제한해 중복 전송을 방지합니다.
- 업로드·다운로드 오류에 파일명과 구체적인 원인을 표시합니다. 파일 사용 중, 경로 없음, 권한·공간 부족, 잘못된 요청·데이터, 연결·시간 초과를 구분합니다.
- 간단 모드 전환은 보류했습니다. 앱과 웹에서 선택기를 제거하고 일반 화면을 유지합니다.
- 이전 테스트 빌드 리소스가 새 빌드에 재귀 포함되던 문제를 수정했습니다.

## 업데이트

기존 앱과 진행 중인 전송을 종료한 뒤 새 설치 파일을 실행하세요. 설치 경로·설정·기기 인증 정보·실제 공유 파일을 유지합니다. 포터블은 ZIP 전체를 새 폴더에 압축 해제하세요. 기존 공개 파일과 태그는 변경하지 않습니다.

앱 메시지는 양쪽에서 이 기능을 지원하는 버전을 사용해야 합니다. 지원하지 않는 이전 호스트에서는 메시지 버튼을 표시하지 않습니다. 기존 필수 파일 전송 규격(v3)은 유지하며, 더 오래된 비호환 규격에는 업데이트 안내가 표시됩니다.

## 알려진 제한

- 이 버전은 코드 서명되지 않은 preview입니다.
- 웹 접속은 여전히 HTTP입니다. PIN·파일·메시지가 암호화되지 않으므로 신뢰하는 로컬 네트워크에서만 사용하고 민감한 자료는 공유하지 마세요. 웹 암호화 문제를 해결한 릴리스가 아닙니다.
- 메시지/알림은 앱·웹페이지가 실행 중일 때 동작합니다. 강제 종료·네트워크 단절에서는 호스트 세션이 만료되거나 해제될 때 정리될 수 있습니다. 직접 저장한 대화 파일은 유지됩니다.
- Windows 알림은 OS 허용·방해 금지 설정의 영향을 받습니다. 웹 토스트는 OS 알림이 아니며 페이지 밖에는 표시되지 않습니다.
- 자동화 검증과 분리된 설치 업그레이드 검증을 사용합니다. 이번 릴리스에서 실제 Android/Mac/두 PC의 전체 시나리오 또는 실제 Windows 알림 표시를 재검증했다고 주장하지 않습니다.

## English

Adds ephemeral, per-connection host/peer messaging for desktop and web; Windows alerts and permission-free web toasts; clearer transfer diagnostics; and bulk upload destination editing. Manual approval is the default for new settings (switch OFF); ON enables automatic approval. Simple-mode switching is deferred. Existing explicit approval preferences remain unchanged. The mandatory file-transfer wire protocol remains v3 with optional messaging capability negotiation. Close the app before upgrading; extract the full portable ZIP.

Unsigned preview. Web traffic remains unencrypted HTTP, including PINs, files and messages. Use trusted LANs only; this release does not resolve web transport confidentiality. Message history is memory-only unless explicitly exported. OS notification display and physical-device scenarios have not been revalidated for this release.
